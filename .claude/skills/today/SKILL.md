# /today 开工

用户附带的今天情况（可用时间、精力、固定安排），可能为空：$ARGUMENTS

1. 读 `NOW.md` 和 `log/` 下当月文件最后两天的记录。今天的重点属于哪个区域，就再读那个区域的文件（期末周读 `study/exams/` 下的计划）。
   如果能用 Google Calendar，再读今天的日历事件：已经排好的时段按日历来，不重复安排。
2. 用户没说可用时间和精力时，只问一句："今天大概有几小时，精力 1–5？" 用户不想答，就按 NOW.md 的默认计划。
3. 给出今天的安排，总长度不超过 15 行：
   - 主任务 1 个：第一步（10 分钟内能开始的具体动作）、时间预算、完成标准
   - 可选任务最多 1 个
   - 需要的话给时间块（上午 / 下午 / 晚上）
   - 最后一行写："现在就做：<第一步>"
4. 昨天没完成的事不要原样照搬，先缩小，或者拆成更小的第一步。
5. 把计划追加到 `log/YYYY-MM.md` 当天的标题下（标〔计划〕），并更新 NOW.md 的「今天」部分。计划和日历不一致时，按 CLAUDE.md「日历」一节同步改日历。
6. 按 CLAUDE.md 的「保存」步骤提交并推送，commit message 用 `today: YYYY-MM-DD`。
