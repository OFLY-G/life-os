# /done 收工

用户的汇报，可能为空：$ARGUMENTS

1. 用户没说时，只问一句："今天做了什么，哪里卡住了？一两句就行。"
2. 追加到 `log/YYYY-MM.md` 当天的标题下：
   - 结果：完成了什么，标〔自述〕或〔已验证〕（有文件、提交、成绩等）
   - 未完成：哪些没做，原因一句话
   - 卡点：具体卡在哪
   - 明天第一步：一个 10 分钟内能开始的动作
3. 更新 NOW.md：勾掉已完成的，写好明天的第一步；截止日期有变化就改表。明天的时段要调整时，同步改日历（规则见 CLAUDE.md「日历」）。
4. 同一个任务连续两天没完成：问一句具体阻碍，然后把它拆小，不加新任务。
5. 回复不超过 8 行：一句基于事实的肯定（不夸张）+ 明天的第一步。
6. 按 CLAUDE.md 的「保存」步骤提交并推送，commit message 用 `done: YYYY-MM-DD`。
