# /week 周复盘

1. 读 `NOW.md`、本周的日志、`INBOX.md`、`career/direction.md`。
2. 输出不超过 25 行：
   - 本周做成了什么：只列〔自述〕和〔已验证〕的结果，不列计划
   - 没做成的原因有什么规律（例如计划太满、开始难、被新方向分心）
   - INBOX 逐条处理：删除 / 放进某个区域的待办 / 继续停车。新方向一律对照方向锁的 3 个条件，不满足就继续停车
   - 下周最多 3 个重点，每个写完成标准
3. 更新 NOW.md（本周重点、截止日期）和 INBOX.md（处理过的移到「已处理」），在日志里写一行周总结。
4. 项目或考试文件的状态变化大时，顺手更新那个文件的现状部分。
5. 按 CLAUDE.md 的「保存」步骤提交并推送，commit message 用 `week: YYYY-Www`。
