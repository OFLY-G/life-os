# 方向决策 + 方向锁

## 当前决定（2026-11-21）
- **主线：推理框架 / 推理优化，具体是 vLLM-Omni 开源贡献**，目标是 3 个合入 PR 作简历主项目
- **辅线：CUDA 算子基础**，每周 ≤3 小时，服务主线的性能 PR 和面试
- **简历第一版**：先把 vllm_studies（nano-vLLM 类推理框架）整理出来，不等 PR

### 为什么这么定（以后纠结时先读这段）
- **你其实没有换方向。** nano-vLLM 类项目 → 算子基础 → vLLM-Omni，全在「推理优化」这一条线上。框架是主线，算子是做性能 PR 时用的工具。
- **「算子会被 AI 替代」**：没有可靠证据能判断哪一层更安全。更难被替代的是这套能力：找到真实问题 → 测量 → 修改 → 证明有效 → 讲清楚。框架和算子都需要它，合入的 PR 正好能证明它。
- **社区入口已经有了**：11/13 的 vLLM Meetup Singapore 认识了 Inferact（vLLM 创始团队和核心维护者创办的公司）、NVIDIA 等的开发者，还有每周自习活动。他们建议在 Omni 提有深度的 PR。
- **硬件现实**：3060 6GB，所以 PR1 / PR2 选能在 CPU 或小卡上验证的题，PR3 再租卡。

## 🔒 方向锁
**锁定期：2026-11-21 → 2027-01-31**。到期做一次正式复盘；PR1 合入时也可以提前复盘。

锁定期内：
1. 看到新方向、新项目、新文章（小红书、评论区、别人的建议），一句话记进 `INBOX.md`，**当天不研究**
2. 只有在 `/week` 周复盘时，并且**同时满足**下面 3 条，才讨论换方向：
   - 有新的**硬事实**，而不是新观点（例如：维护者明确说不需要；硬件确实无法验证；拿到的实习机会明确要求别的技能）
   - 主线已经认真推进 ≥2 周仍然卡住，而且说得出卡在哪
   - 能写出新方向 2 周内的第一步和完成标准
3. 不满足就继续留在 INBOX，主线照常推进
